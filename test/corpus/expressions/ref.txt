================================================================================
ref identifier
================================================================================
=> ::f
--------------------------------------------------------------------------------
(program (statement_return (expression_ref (identifier))))

ref with only body
================================================================================
=> ::{}
--------------------------------------------------------------------------------
(program (statement_return (expression_ref (anon_function (block)))))

================================================================================
ref with empty parameters
================================================================================
=> ::(){}
--------------------------------------------------------------------------------

	referenced: (anon_function
